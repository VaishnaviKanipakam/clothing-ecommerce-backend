Backend service for a full-stack clothing e-commerce application built using Node.js, Express, and MySQL

##  Features
- User Authentication (JWT)
- Product Management (Men, Women, Kids)
- Cart Management (Add, Update, Delete)
- Order Placement & Order History
- Role-based protected routes
- MySQL relational database
- Modular MVC architecture

## Tech Stack
- Node.js
- Express.js
- MySQL
- JWT Authentication
- bcrypt
- dotenv
- CORS

## Run Locally
- npm install
- npm start

## Server will run on
http://localhost:5000
